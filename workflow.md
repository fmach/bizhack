Follow this workflow:
- Run the data analysis on the “series-1” file using the analyze_series.py script.
- Use the skills defined in the “expert_skill.md” file.
- Load the building's water consumption data from the “data.csv” file, as well as the results of its statistical analysis from the “analysis.csv” file.
- Perform a detailed analysis of all data and results. For the 3 most significant results (select concrete numbers), create a report that includes each number and explains it.
- Create an executive summary (maximum 5 sentences) of the analysis.
- Record the results of the analysis in the file “technical_report.md”.
- Use the skills defined in the file “storyteller_skill.md”.
- Based on the five most significant results, create a brief description of the analysis in the form of a story (maximum 5 sentences with 3 numbers).
- Record the results of the analysis in the file “story-like_report.md”.
